# Roadmap

## Current public baseline

Pool Cockpit v3.0.0 is the first public release.

It includes:

- water-quality monitoring;
- filtration monitoring and scheduling;
- heat-pump monitoring and control;
- energy monitoring;
- Blue Connect support;
- historical trends;
- treatment journal;
- contextual recommendations;
- automated JavaScript and Python tests;
- reproducible frontend builds.

## Documentation

Current priority:

- create end-user installation documentation;
- document initial configuration;
- add annotated dashboard screenshots;
- document Blue Connect integration;
- document heat-pump configuration;
- add troubleshooting guidance;
- separate user documentation from developer documentation.

## Packaging and installation

Future improvements may include:

- simplified installation and upgrades;
- improved Home Assistant packaging;
- evaluation of HACS-compatible distribution.

## User experience

Planned improvements include:

- clearer first-run configuration;
- improved entity selection;
- additional contextual help;
- continued mobile and desktop interface refinements.

## Development

Future development will continue to preserve:

- reproducible builds;
- automated testing;
- separation between calculation and equipment control;
- non-regression of existing installations.
