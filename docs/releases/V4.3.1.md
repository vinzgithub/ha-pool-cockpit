# 🌊 Pool Cockpit V4.3.1 — Correctif de l'installateur

**V4.3.1 est une version de maintenance de l'installation.** Le code fonctionnel et le bundle JavaScript sont **identiques à V4.3.0** : les fonctions de suivi de la piscine et d'hivernage ne changent pas. Le correctif porte sur la reconnaissance et la sauvegarde des installations Home Assistant existantes.

## Problème corrigé

L'installateur de la V4.3.0 publiée supposait que la ressource JavaScript était obligatoirement dans `configuration.yaml` et cherchait le nom de carte `custom:pool-cockpit-card`. Certaines installations officielles utilisent au contraire une ressource enregistrée par l'interface Home Assistant dans `.storage/lovelace_resources` et une carte `custom:pool-dashboard-card`.

Le nouvel installateur reconnaît désormais ces installations sans convertir le tableau de bord. Il conserve les autres ressources Lovelace et sauvegarde aussi le fichier des ressources lorsqu'il est modifié. Le retour arrière restaure le tableau de bord, la configuration, le backend, le JavaScript et les données sauvegardées.

## Installation / mise à jour

Pour **Home Assistant Core ou Docker** disposant d'un accès au dossier contenant `configuration.yaml` :

```bash
git clone --branch v4.3.1 --depth 1 https://github.com/vinzgithub/ha-pool-cockpit.git
cd ha-pool-cockpit
sh install.sh --config /chemin/vers/config --dry-run
```

Vérifier que le résultat indique `READY: upgrade_storage` (ressource Lovelace enregistrée dans l'interface), `READY: upgrade` (ressource YAML) ou `READY: fresh`. **Si l'installateur affiche STOP, ne rien forcer.**

Après une sauvegarde complète de Home Assistant, **arrêter Home Assistant** et seulement ensuite exécuter :

```bash
sh install.sh --config /chemin/vers/config --yes
```

Redémarrer Home Assistant **manuellement**, puis vérifier l'affichage et les équipements.

L'installateur **ne redémarre aucun conteneur** et ne pilote aucun matériel. Le mécanisme de retour arrière utilise le chemin `BACKUP:` indiqué à l'installation (Home Assistant arrêté).

**Épinay / Docker :** le dossier de configuration identifié est `/home/homeassistant/config` sur l'hôte LXC 102. Le conteneur Docker Home Assistant monte ce dossier comme `/config`. Utiliser le chemin correspondant à l'environnement dans lequel la commande est exécutée.

## Compatibilité et sécurité

- V4.2.1 officielle : migration accompagnée d'une sauvegarde et de vérifications d'intégrité.
- V4.3.0 déjà installé : aucun changement fonctionnel n'est requis ; la V4.3.1 corrige surtout le programme d'installation.
- Versions personnalisées, doute sur la ressource, ressources en double : refus de la migration plutôt qu'écrasement.
- **Antigel désactivé par défaut** après migration. Les essais automatisés ne prouvent pas une protection réelle du bassin contre le gel. Respecter les sécurités hydrauliques et une protection matérielle adaptée.
- Les **commandes PAC restent verrouillées** en version publique.

Pour une installation complète, télécharger l'archive **Source code (zip)** de ce tag et utiliser l'installateur inclus. Les deux actifs `pool-cockpit.js` et `pool-cockpit.js.sha256` servent à contrôler le bundle **V4.3.0 inchangé**, et **ne constituent pas à eux seuls un installateur**.
