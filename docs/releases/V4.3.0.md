# 🌊 Pool Cockpit V4.3.0 — La piscine, même en hiver

**Une interface plus claire pour comprendre et piloter votre piscine dans Home Assistant.**

La V4.3.0 apporte l'**hivernage actif**, la surveillance du risque de gel, le suivi individuel des équipements et un installateur commun aux nouvelles installations et aux mises à jour depuis une V4.2.1 officielle.

## Ce qui change pour vous

### ❄️ L'hivernage actif, sans perdre votre programmation

- Passez explicitement en mode **Normal**, **Hivernage actif** ou **Maintenance**.
- Proposez une filtration réduite pour la saison froide (par exemple 4 heures de 2 h à 6 h), à confirmer avant application.
- Retrouvez votre ancienne programmation en revenant au mode Normal.
- Signalez séparément une PAC, un Blue Connect ou un Flipr hiverné, puis réactivez chaque équipement quand vous le décidez.

### 🛡️ Une surveillance antigel qui explique ses décisions

Avec une sonde locale adaptée, le système peut demander une circulation supplémentaire en cas de froid, **même en dehors du planning**. Les seuils initiaux configurables sont de 3 °C pour la demande de marche et de 5 °C pour la sortie, avec des temporisations.

L'interface distingue **la demande de commande**, **l'état de la pompe observé par Home Assistant** et **la vérification du débit** lorsqu'un capteur de débit est présent. Les sécurités de marche à sec et les interdictions hydrauliques restent prioritaires. Une sonde indisponible ou une circulation non confirmée déclenche une alerte.

**Cette fonction ne garantit pas le hors-gel :** elle dépend d'une alimentation électrique, d'un Home Assistant fonctionnel, de sondes et d'une pompe disponibles. Elle ne remplace pas une protection matérielle autonome. L'antigel est **désactivé par défaut** après mise à jour ; contrôlez votre installation réelle avant activation.

### 🎨 Une interface plus agréable

- **Vue d'ensemble** : synthèse courte et lisible.
- **Planning** : conseils, durée réellement programmée et frises horaires.
- **Équipements** : quatre cartes compactes et statuts distincts.
- **Thème Océan** conservé, avec mise en page responsive et mode Démonstration isolé.

## Installation : simple et prudente

L'installateur reconnaît une installation **neuve** ou une **V4.2.1 officielle** sur Home Assistant Core/Docker. Prévoir Python 3 et Git.

```bash
git clone --branch v4.3.0 https://github.com/vinzgithub/ha-pool-cockpit.git
cd ha-pool-cockpit
sh install.sh --config /chemin/vers/config --dry-run
# Effectuer une sauvegarde complète, arrêter Home Assistant, puis :
sh install.sh --config /chemin/vers/config --yes
# Redémarrer Home Assistant manuellement.
```

- `--dry-run` : vérifie sans toucher aux fichiers.
- `--yes` : sauvegarde, copie le frontend et le backend et prépare la migration du stockage.
- `--rollback` : restaure les données et le code de la version précédente avec Home Assistant arrêté.
- Aucun redémarrage ni contrôle physique n'est déclenché automatiquement par l'installateur.

## Tests et garanties

Les tests Python, JavaScript et navigateur ont réussi sur GitHub Actions. La recette a été effectuée sur une **instance Home Assistant isolée**, avec des équipements simulés. Aucun test de résistance au gel d'une véritable piscine n'est revendiqué.

Le bundle distribué correspond au fichier `release/v4.3.0/pool-cockpit.js` du dépôt ; vérifier son empreinte SHA-256 dans l'actif `pool-cockpit.js.sha256` avant installation.

**À télécharger :** `pool-cockpit.js` et son empreinte `pool-cockpit.js.sha256`. Pour une installation complète, utilisez l'archive « Source code » fournie automatiquement par GitHub pour ce tag : elle comprend aussi les scripts, l'intégration Python, les images et les guides.
