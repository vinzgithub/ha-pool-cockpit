# Pool Cockpit V4.1.0 — Installation complète

Livraison complète de Pool Cockpit : moteur V4 (six onglets), backend Home Assistant, interface Océan et sélecteur Réel/Démonstration isolé.

- Installation neuve directement avec `git clone` et `python3 install_v41.py --config /config --dry-run`, puis `--yes`.
- Mise à jour contrôlée depuis V4.0.0 avec `--upgrade --dry-run`, puis `--upgrade --yes`.
- ZIP autonome incluant tous les composants requis et un manifeste SHA-256 interne.
- Commandes fictives filtration/PAC/éclairage, météo placée en haut, corrections Configuration et Historique.
- **Démarrage sans capteur :** Démonstration présélectionnée et affichée immédiatement. Le mode Réel signale clairement qu'aucun appareil n'est configuré, sans écran gris. Dès qu'un appareil est configuré, Réel devient le mode initial. Aucun appareil de démo n'est conservé dans les paramètres réels du navigateur.
- Filtration de démonstration : 07:00–14:00 et 15:00–22:00, soit 14 h.

**Périmètre :** Home Assistant Core/Docker avec accès à la configuration. Installations non reconnues refusées ; ni migration V3 automatique, ni mise à niveau forcée. Sauvegarde complète HA recommandée avant toute écriture. L'installateur ne redémarre pas Home Assistant.

Lire `release/v4.1.0/INSTALLATION.md` pour les commandes et le retour arrière.
