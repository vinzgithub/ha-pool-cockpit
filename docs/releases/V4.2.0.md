## Pool Cockpit, c’est quoi ?

**Pool Cockpit est un tableau de bord pour surveiller et gérer sa piscine depuis Home Assistant**, une plateforme domotique qui rassemble les informations de vos appareils connectés.

Plutôt que d'ouvrir plusieurs applications pour consulter la température de l'eau, le pH, la filtration ou les programmations, Pool Cockpit regroupe ces informations dans **une seule interface**, accessible depuis votre Home Assistant sur ordinateur, tablette ou téléphone.

Ses six rubriques — **Vue d'ensemble, Conseils, Mesures, Équipements, Planning et Historique** — permettent de comprendre l'état de la piscine et de retrouver facilement les informations utiles. Les fonctions réellement disponibles dépendent des capteurs et équipements installés.

## Faut-il avoir une piscine connectée ?

**Non, pour essayer. Oui, pour utiliser des mesures réelles.** Pool Cockpit propose deux modes :

### Mode Démonstration : pour découvrir sans matériel

Vous pouvez parcourir les écrans avec **des données fictives**, même sans piscine, sans sonde et sans intégrations d'équipements supplémentaires. **Home Assistant reste nécessaire** pour afficher Pool Cockpit. Aucune commande du mode Démonstration n'agit sur les vrais équipements.

### Mode Réel : pour suivre sa propre piscine

Vous devez disposer de **Home Assistant** et y avoir installé et configuré les **intégrations correspondant à vos capteurs et équipements**, avant de pouvoir exploiter leurs données dans Pool Cockpit.

Par exemple, pour certaines sondes compatibles :
- [**Blue Connect Local**](https://github.com/Adrien40/ha-blue-connect-local), projet indépendant développé par **Adrien40**, peut remonter des mesures Blue Connect dans Home Assistant.
- [**Flipr Local**](https://github.com/Adrien40/ha-flipr-local), également développé par **Adrien40**, peut faire de même avec des sondes Flipr compatibles.

Ces intégrations **ne font pas partie de Pool Cockpit** et ne sont nécessaires que si vous utilisez le matériel concerné. D'autres intégrations Home Assistant peuvent convenir selon votre installation. Une fois les entités disponibles dans Home Assistant, vous pouvez les associer à Pool Cockpit.

## Les nouveautés de la V4.2.0

La V4.2.0 simplifie principalement la mise en place de l'interface :

- **Un seul fichier JavaScript**, `pool-cockpit.js`, pour le tableau de bord et le mode Démonstration.
- Une carte Lovelace unique : `custom:pool-cockpit-card`.
- Les paramètres, capteurs et composants Home Assistant existants sont préservés lors de la mise à jour documentée depuis la V4.1.0.
- Les anciennes ressources JavaScript peuvent être supprimées après vérification du bon fonctionnement.
- Les modes Réel et Démonstration ont été vérifiés sur une installation Home Assistant existante.

## Installation et mise à jour

**Nouvel utilisateur ?** La V4.2.0 peut désormais être installée **directement depuis le dépôt GitHub**, sans devoir installer la V4.1.0 au préalable. L'installateur `install_v42.py` est prévu pour une installation neuve compatible **Home Assistant Core / Docker** disposant d'un accès au dossier de configuration. Sauvegardez Home Assistant avant toute intervention.

👉 [**Consulter le guide de première installation (en français)**](https://github.com/vinzgithub/ha-pool-cockpit/blob/main/README.fr.md#installer-directement-pool-cockpit-v420)

**Vous utilisez déjà la V4.1.0 ?** Suivez le [guide de mise à jour et de retour arrière](https://github.com/vinzgithub/ha-pool-cockpit/blob/main/release/v4.2.0/README.md), sans utiliser l'installateur réservé aux nouvelles installations.

Les deux fichiers joints à cette release (`pool-cockpit.js` et `pool-cockpit.js.sha256`) concernent **l'interface JavaScript**. Ils ne constituent pas, à eux seuls, une installation neuve complète.

## Repères techniques

- Ressource Lovelace : `/local/ha-pool-dashboard/pool-cockpit.js?v=4.2.0`.
- Type de carte : `custom:pool-cockpit-card`.
- Les identifiants internes historiques sont conservés pour la compatibilité.

📷 [Voir les captures de l'interface V4.2.0 et les fonctionnalités](https://github.com/vinzgithub/ha-pool-cockpit/blob/main/README.fr.md).

**Sécurité :** Pool Cockpit facilite le suivi, mais ne remplace ni l'entretien de l'eau, ni les contrôles manuels, ni les dispositifs de sécurité des équipements.
