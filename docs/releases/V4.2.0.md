## Nouveautés de la V4.2.0

Cette version simplifie l'utilisation et la distribution de Pool Cockpit :

- **Un seul fichier JavaScript** (`pool-cockpit.js`) pour l'interface et les modes Réel et Démonstration.
- Une seule carte Lovelace publique : `custom:pool-cockpit-card`.
- Les capteurs, réglages et composants Home Assistant existants restent en place lors d'une mise à jour depuis V4.1.0 suivant la procédure documentée.
- Les anciennes ressources JavaScript peuvent être retirées une fois la migration vérifiée.
- Les deux modes ont été vérifiés sur une installation Home Assistant.

## Installation et mise à jour

**Nouvelle installation :** la V4.2.0 s'installe directement depuis le dépôt GitHub sur une installation compatible **Home Assistant Core / Docker**, avec l'installateur `install_v42.py`. Il n'est plus nécessaire d'installer la V4.1.0 auparavant. Sauvegardez votre configuration avant toute modification.

**Installation existante en V4.1.0 :** utilisez le [guide de mise à jour et de retour arrière](https://github.com/vinzgithub/ha-pool-cockpit/blob/main/release/v4.2.0/README.md) et non l'installateur destiné aux installations neuves.

**Fichiers joints :** `pool-cockpit.js` et `pool-cockpit.js.sha256` correspondent au frontend et à son empreinte de contrôle ; ils ne constituent pas un paquet complet d'installation neuve.

## Repères techniques

- Ressource Lovelace : `/local/ha-pool-dashboard/pool-cockpit.js?v=4.2.0`
- Carte : `custom:pool-cockpit-card`
- Les anciens identifiants internes nécessaires à la compatibilité sont conservés.
