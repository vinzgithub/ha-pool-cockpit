# Pool Cockpit V4.2.1 — candidate corrective, PR #11

Cette candidate vise les défauts de visibilité du bandeau Météo-France sur smartphone et l'ouverture de ses détails dans l'onglet Conseils. Le bandeau unique est intégré directement à la coquille V4 avant la navigation. Les règles métier, Home Assistant, automatisations, commandes et paramètres sont inchangés.

**Ne pas déployer avant validation** des tests CI et de la revue. Pas de release ni tag. Un seul bundle : `release/v4.2.1/pool-cockpit.js`.

Voir `docs/releases/V4.2.1.md` pour les tests et limites, notamment Safari/iOS et la validation sur un Lovelace réel.
